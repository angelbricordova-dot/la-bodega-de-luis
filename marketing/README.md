# Marketing de TuBodega

Todo lo necesario para hacer los videos de lanzamiento.

| Archivo | Para qué |
| --- | --- |
| [PROMPT_PARA_VIDEOS.md](PROMPT_PARA_VIDEOS.md) | El texto para pegar en la sesión que hace los videos |
| [VIDEO_BRIEF.md](VIDEO_BRIEF.md) | Producto, público, tono, precios, marca y lo que no se puede decir |
| [GUIONES.md](GUIONES.md) | Guiones escena por escena: promo, teaser, tutoriales, plan Pro, horizontal y estados |
| [ELEVENLABS.md](ELEVENLABS.md) | Voz, música y efectos de sonido con prompts listos |
| `assets/screens/` | 27 pantallas reales de la app |
| `assets/clips/` | 5 grabaciones reales de la app |
| `assets/brand/` | Logo |
| `capture.mjs` | Vuelve a generar pantallas y clips desde la app (`npm run dev` y luego `node marketing/capture.mjs`) |
